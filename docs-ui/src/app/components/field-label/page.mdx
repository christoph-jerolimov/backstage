## Usage

<CodeBlock code={fieldLabelUsageSnippet} />

`FieldLabel` is what `TextField`, `Select`, `Combobox`, and the other form
field components use internally to render their label, secondary label, and
description. It is exported so that you can reuse the same layout around your
own inputs.

The component renders nothing when no `label` is provided.

## API reference

<PropsTable data={fieldLabelPropDefs} />

This component also accepts all standard HTML `div` attributes.

### With a custom input

When the label is used with a plain input, connect them with `htmlFor` and
`id`. Use `descriptionId` together with `aria-describedby` so that screen
readers also announce the description.

### With React Aria field components

Inside a React Aria field component such as `TextField`, pass
`descriptionSlot="description"`. The label and description are then connected
to the input automatically, without any ids.
