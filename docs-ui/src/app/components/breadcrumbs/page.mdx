## API reference

<PropsTable data={breadcrumbsPropDefs} />

The component renders a `nav` landmark labeled "Breadcrumbs" and accepts any other `nav` attribute, such as `aria-label` or `id`.

## Examples

### Single item

A trail with a single item, such as the root page of a plugin, renders that item as a link.

<Snippet open preview={<SingleItem />} code={singleItem} />

### Long labels

Labels truncate when they run out of space. Truncated labels show their full text in a tooltip on hover and focus. The current page takes the remaining space.

<Snippet open preview={<WithLongLabels />} code={withLongLabels} />

### Many items

Trails with five or more items collapse the middle items behind an ellipsis button. The button opens a menu with the collapsed links. The first item, the parent of the current page, and the current page stay visible.

<Snippet open preview={<WithManyItems />} code={withManyItems} />

### In the plugin header

Pass the trail to [PluginHeader](/components/plugin-header#breadcrumbs). The header renders the breadcrumbs in place of its title.

<Snippet open preview={<InPluginHeader />} code={inPluginHeader} />
