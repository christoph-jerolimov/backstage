## API reference

<PropsTable data={separatorPropDefs} />

A horizontal separator renders as an `hr` element. A vertical separator renders
as a `div` with the `separator` role and `aria-orientation` set, so assistive
technologies announce both the same way. This component also accepts all
standard HTML attributes of the rendered element.

## Examples

### Vertical

Use a vertical separator between items placed side by side. It stretches to
the height of its flex container, so no explicit height is needed.
