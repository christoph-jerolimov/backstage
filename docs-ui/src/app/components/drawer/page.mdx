The main drawer container. By default it renders as a modal sheet that

## Examples

### Placement and size

Use `placement` to pick the edge the drawer slides in from. A left or right
drawer takes the full height of the viewport and is sized with `width`.

<Snippet
  align="center"
  py={4}
  preview={<PreviewPlacement />}
  code={drawerPlacementSnippet}
/>

A top or bottom drawer takes the full width of the viewport and is sized with
`height`. Without a `height` it grows with its content.

<Snippet
  align="center"
  py={4}
  preview={<PreviewBottom />}
  code={drawerBottomSnippet}
/>

### Hidden backdrop

Set `hideBackdrop` to keep the drawer modal without dimming the page behind it.
The page stays blocked until the drawer closes.

<Snippet
  align="center"
  py={4}
  preview={<PreviewHiddenBackdrop />}
  code={drawerHiddenBackdropSnippet}
/>

### Non-modal drawer

Set `isNonModal` to keep the page interactive while the drawer is open. A
non-modal drawer has no backdrop, does not trap focus, does not block
scrolling, and cannot be swiped away. Combine it with `isDismissable={false}`
to build a persistent side panel that only closes through its own controls.

<Snippet
  align="center"
  py={4}
  preview={<PreviewNonModal />}
  code={drawerNonModalSnippet}
/>
