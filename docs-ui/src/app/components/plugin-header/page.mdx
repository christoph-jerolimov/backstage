### Breadcrumbs

Pass a trail to the `breadcrumbs` prop to show where the current page sits in the plugin. The trail replaces the title in the toolbar, and the title stays available to screen readers as the page heading. The last entry is the current page. Long labels truncate with a tooltip, and trails with five or more entries collapse the middle entries behind an ellipsis menu.

The header renders the trail with the [Breadcrumbs](/components/breadcrumbs) component. Use that component directly only for trails outside the header.

<Snippet preview={<WithBreadcrumbs />} code={withBreadcrumbs} open />
