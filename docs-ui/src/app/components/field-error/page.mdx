## Usage

<CodeBlock code={fieldErrorUsageSnippet} />

`FieldError` is what `TextField`, `Select`, `Combobox`, and the other form
field components use internally to display validation errors. It is exported
so that you can reuse it around your own inputs.

The component reads the validation state of the surrounding field from the
React Aria `FieldErrorContext`. The built-in field components provide this
context for you. Around a custom input, provide it yourself with
`FieldErrorContext.Provider` from `react-aria-components`, as shown in the
examples below. The component renders nothing while `isInvalid` is `false`.
